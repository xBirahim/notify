# notifyctl

`notifyctl` is a macOS CLI to send and manage local notifications with stable, scriptable output.

## Requirements

- macOS 13+
- Swift 6+

## Quickstart

```bash
swift build
swift run notifyctl --help
```

## Roadmap

Current MVP targets:

- `status`
- `request-permission`
- `send`
- `dismiss`
- `list`
- `update`
